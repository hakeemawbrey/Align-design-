# Month 2 boost · batch m39 · Star Talk Game Night: Full Games (star_talk post, page 35)

Series key `xgame`, prefix `kxgn`. Episodes 1–8, **all long (2 min)**. Continues *Star Talk Game Night* (ngne01–24,
promo/films/next30/b07.md, b08.md): the same studio, host and tone. THE STARS host (gold star, pixel mic), two signs at
podiums with buzzers, Pisces cries in the front row with a tissue box (when Pisces plays, it cries at the podium and
Cancer sobs in the front row), and the running gag stays: **the kindest answer scores, never the fastest
("SPEED: 0 PTS").** The prize is a talk card, face down, then flipped.

No end card, no card transition, no logo, no "Align" on screen. `DURATION` = story length (~120 s).

Shared long-format set: `promo/films/kxgne01/fullgame.js` (imported read-only by kxgne02–08). It reuses the old
gamekit's exported helpers read-only (props, tears, confetti, sprite frame) and redraws the stage for 2 minutes; it
imports nothing from endcard.js or cardfx.js. Hook effects come from `promo/films/hookkit.js`.

**The full-game timeline (≈120 s):**
- **0–6 s, hook:** frame 0 is mid-chaos (per row) with the hook line up. At ~0.5 s a pattern break (record scratch + freeze,
  or whip zoom). THE STARS: the welcome promises the payoff: **"wait for the final. it's worth double."** A sticker
  "WAIT FOR THE FINAL ×2".
- **6–10 s, the contestants:** name cards slam in with a joke stat each ("ARIES · patience: loading").
- **10–70 s, three rounds of 20 s** (chapter stickers ROUND 1 / 2 / 3): FINISH THE TEXT · GREEN FLAG OR RED FLAG ·
  WHAT WOULD YOU DO? Per round: prompt card drops, the first buzz (BZZT, "SPEED: 0 PTS"), answer 1, answer 2, a
  twist (a changed answer or a gag), THE STARS' verdict, +1 KIND, then the **AUDIENCE CAM** insert: Pisces sobbing.
- **70–90 s, LIGHTNING ROUND** (chapter sticker, a countdown clock): four quick yes/no situations, both slam GREEN or
  RED flags, a point each for the kind call.
- **90–110 s, THE FINAL ×2** (chapter sticker, lights down, drum roll): one big situation, double points.
- **110–120 s, the payoff:** final score, confetti, the prize card flips, THE STARS' last line, then the ending.
- A new beat every 8–10 s and a slow camera drift + punch-ins, so nothing is static for more than 3 s.
