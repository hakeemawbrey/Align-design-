## Plugin-API findings

- `text.textAutoResize='HEIGHT'` **then** `resize(w, h)` silently flips the
  node back to `NONE` (fixed box, height stays 10). Do `resize` first, then
  set `textAutoResize='HEIGHT'`. Same for auto-layout frames: `resize()` after
  `counterAxisSizingMode='AUTO'` turns it FIXED — resize first, or set
  `layoutSizingVertical='HUG'` after appending children.
- Instance children can be edited (text characters, `visible`), but nothing
  can be appended to an instance — the value column and pencil sit as
  siblings in the screen frame at the row's coordinates.
- Rotated rects: position via `absoluteBoundingBox` delta after rotation
  (rotation is about the node origin).
