# Benchmarks for Core Flow — the deck, the match, the read

Core Flow is the product's spine: deal a deck, read a card, align, match, talk.
Stardust has none of those screens, so it stays the reference for the **visual
language** while the UX comes from the apps that ship this flow for money.

Pulled by revenue via Appllama `search_apps`.

| App | Revenue/mo | Ratings | The relevant flow |
|---|---|---|---|
| **Feeld** | **$4M** | 99,821 | Profile Discovery, Likes & Pings |
| Boo | $900K | 207,741 | onboarding-heavy |
| **The Pattern** | $400K | 14,955 | **Bonds — 14 screens** |
| Paired | $200K | 206,611 | Relationship Checkup |

Feeld out-earns everything else here four to one, and its positioning —
literary, non-mainstream, text-first — is much closer to Align than Tinder is.
The Pattern is Align's conceptual twin: astrology applied to a relationship
between two charts.

## The Pattern — `Bond Insight Dashboard`

The direct reference for **S-21 Alignment**.

```
two overlapping circular avatars
[ You ⌄ ]   [ Taylor ⌄ ]           <- who is being compared, both editable
◎◎ Romantic Connection ⌄            <- the relation type
┌──────────────────────────────────┐
│        EXTRAORDINARY             │  <- blue→purple gradient, full width
└──────────────────────────────────┘
Snapshots
┌ beige card ─────────────────────┐
│ Your lives are aligned – by ... │
└─────────────────────────────────┘
        • ○ ○ ○ ○ ○                 <- six snapshots, swiped
Bond | Transits | Signs | Chart     <- segment tabs
RELATIONSHIP DYNAMICS
∞ LIFE CHANGING  ...                 <- insight card list
```

**The verdict is one loud word.** Not a score out of ten, not a percentage —
`EXTRAORDINARY`, full-width, all caps, in a gradient pill. Align says
*"A strong pull"* in quiet serif italic. The Pattern's version is the stronger
device and Align already owns the holo gradient to build it from.

Worth noting: its relation-type icon is **two interlocking circles** — a vesica
piscis, which is already Align's own motif. Convergent, not borrowed.

## The Pattern — `Bond Insight Detail`

```
MOON CONJUNCT ANTIVERTEX                    <- the real aspect, small caps
Vertex: Past Link & Future Destiny   ☽ ♂ Ax <- human title + the planets
┌ beige panel, full bleed ────────────────┐
│ SUMMARY                                 │
│ Your connection with Taylor could feel  │
│ incredibly deep – like you two have ... │
│ ...text fades to nothing...             │
│         ( Go Deeper+ )                  │
└─────────────────────────────────────────┘
```

Two devices:

1. **Technical eyebrow, human title.** The real aspect is named above a
   plain-English heading. Credibility and legibility at once — the same reason
   the Virgo/AIR error mattered.
2. **The paywall is a fade, not a wall.** The body text dissolves to
   transparent with the upgrade pill floating over it. You can see that there
   is more, and roughly how much. Align's locked reads currently cut to a
   card; a fade is better and cheaper to build.

## Feeld — `Profile Bio Detail`

```
...long-form bio, left aligned, no card at all...
┌ Hidden bio ─────────────────────┐   ( − )  ( ♡ )   <- floating, circular
│  👁̸  Tap to reveal              │
└─────────────────────────────────┘
```

**Feeld hides part of the profile behind a tap.** A greyed card, an eye-slash,
`Tap to reveal`. The highest-earning app in the category runs progressive
disclosure on profile content — which is Align's entire premise, arrived at
independently. It is the clearest evidence yet that the veil is not a gimmick.

Its actions are **floating circular buttons** over the tab bar rather than a
bar of their own. Align's `↑ RELEASE / ALIGN ↑` names the gesture instead,
which is more distinctive; keeping ours.

## What Core Flow takes

| Screen | Device | From |
|---|---|---|
| S-21 Alignment | one-word gradient verdict | The Pattern |
| S-21 Alignment | segment tabs across read dimensions | The Pattern |
| S-21 Alignment | paginated snapshots | The Pattern |
| S-06 Expand | technical eyebrow over human title | The Pattern |
| S-08 Veil / locked reads | text-fade gate instead of a locked card | The Pattern |
| S-08 Veil | eye-slash + tap-to-reveal on hidden content | Feeld |
| everything | the glow, starfield, geometry and type | Stardust |

**The card itself is not changing.** The deck card design stays exactly as it
is; the deck-state screens clone it rather than redraw it.
